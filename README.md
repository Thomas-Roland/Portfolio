# Portfolio de Thomas Roland

Bienvenue sur mon portfolio ! Ce site présente mes projets, compétences et expériences professionnelles.

## Aperçu
Ce portfolio met en avant mes réalisations à travers une galerie d’images, un CV téléchargeable et des informations de contact.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript

## Utilisation
1. Clonez le dépôt :
   ```bash
   git clone <url-du-repo>
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur.

## Structure du projet
- `index.html` : page principale du site
- `index.js` : scripts JavaScript
- `assets/` : images, CV, favicon, et feuille de style
- `README.md` : ce fichier
